# Maître Sandrine MONGOUE

Site de démonstration (prospection) — priorité **A** — Douala 9e charge, Akwa.

**Ouvrir le site :** double-cliquez sur `index.html`. Aucune installation. Six pages par langue (accueil, domaines, pièces à fournir, l'étude, questions, contact), avec photos d'illustration Unsplash (connexion internet nécessaire pour les voir).
**Langues :** Français (`index.html`) + anglais (`en/`).
**Note :** nouvelle version générée comme les 17 autres sites. Le site React/Vite d'origine reste dans `01-mongoue-sandrine`.
**Design :** thème moderne, palette violet (reprend le violet du site d'origine).
**Angle :** site FR/EN orienté diaspora (rendez-vous à distance, pièces à fournir). Le domaine smnotaire.com est acheté mais vide : ce site peut y être publié.

Le bandeau jaune en haut des pages signale une maquette : à retirer quand l'étude a signé.
Faits, sources et points à confirmer avec l'étude : voir `CLAUDE.md`.
