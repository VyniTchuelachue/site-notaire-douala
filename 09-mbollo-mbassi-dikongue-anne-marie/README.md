# Maître Anne Marie MBOLLO MBASSI

Site de démonstration (prospection) — priorité **B** — Douala 2e charge, Bali.

**Ouvrir le site :** double-cliquez sur `index.html`. Aucune installation. Six pages par langue (accueil, domaines, pièces à fournir, l'étude, questions, contact), avec photos d'illustration Unsplash (connexion internet nécessaire pour les voir).
**Langues :** Français (`index.html`) + anglais (`en/`).
**Design :** thème editorial, palette terracotta.
**Angle :** Visibilité de base : fiche Google + site simple + email pro.

Le bandeau jaune en haut des pages signale une maquette : à retirer quand l'étude a signé.
Faits, sources et points à confirmer avec l'étude : voir `CLAUDE.md`.
